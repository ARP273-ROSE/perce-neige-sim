== 3. Premier galet : critère de hauteur ⇔ coude vers le bas ==
  coude(R1)           = −(D² + D·L − 2ah) / (2·D·a)
  hauteur au droit R1 = −L·(D² + D·L − 2ah) / (2·(D + L)·a)
  hauteur / coude     = D*L/(D + L)  (> 0 : mêmes signes)
  ⇒ coude ≤ 0 (le galet porte) ⇔ la chaînette plus longue passe sous R1 ;
    au changement de R1 les deux s'annulent : le câble quitte le galet
    tangentiellement, à 0 mm, sans angle.
  cosh exact, a = 1585 m, L = 15,1 m : D critique = 13.364 m, coude = 5.29e-06 °
  (ancien critère D(D + L) ≥ 2ah : D = 13.364 m)
